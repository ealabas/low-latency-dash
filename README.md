# low-latency-dash

## Environment

- Ubuntu 22.04
- OBS Studio
- FFmpeg compiled from source with a one-line patch to `libavformat/dashenc.c`
- NGINX
- Node.js 18+ with the [modified node-gpac-dash](https://github.com/maxutility2011/node-gpac-dash)
- A modern browser with [dash.js](https://github.com/Dash-Industry-Forum/dash.js) (low-latency mode enabled)
